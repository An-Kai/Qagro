## 1. SoilGrids — статус: ЧАСТИЧНО (5/10), шаг 2 для soil ПРОПУЩЕН

Артефакты: `src/soil.py`, `data/raw/soil_*.json` (10 файлов),
`data/processed/soil.csv` (5 строк).

| district_en | nitrogen (г/кг) | ph | soc (г/кг) | clay (г/кг) |
|-------------|-----------------|----|------------|-------------|
| Burabay | 3.905 | 6.40 | 55.60 | 26.40 |
| Sandyktau | 4.430 | 7.00 | 51.10 | 28.40 |
| Tselinograd | 3.935 | 7.05 | 69.30 | 26.70 |
| Zerenda | 3.455 | 6.80 | 51.55 | 25.00 |
| Zhaksy | 3.645 | 7.15 | 73.00 | 24.05 |
| Atbasar, Esil, Shortandy, Bulandy, Kokshetau | — | — | — | — (пропуск, см. ниже) |

Что произошло (всё в логах `src/soil.py`, таймаут 20с, моков нет):
- Канонический comma-запрос из ТЗ
  (`property=nitrogen,phh2o,soc,clay&depth=0-5cm,5-15cm`) стабильно отвечает
  HTTP 500 «Internal Server Error» по всем 10 районам — серверный баг
  SoilGrids (поодиночные свойства работают; проверено). Задокументированный
  фолбэк в `src/soil.py`: те же свойства поодиночке с того же эндпоинта
  (`depth=0-5cm&depth=5-15cm` повторными параметрами), значения склеены
  в `data/raw/soil_{en}.json` (поле `_qagro.mode=per-property-fallback`).
  Ретраи при 429/timeout (лимит API ~5 запр/мин, пауза 15с между районами).
- 5 пропусков — genuine-маска SoilGrids: по центроидам Atbasar, Esil,
  Shortandy, Bulandy, Kokshetau API возвращает `mean=null` на ОБЕИХ глубинах
  по ВСЕМ 4 свойствам (прямая проверка curl 2026-09-19; повторный запрос
  вернул те же null — не транзиент). Вероятно, центроиды попали
  в маскированные пиксели (города/не-почва). Координаты не двигали —
  это было бы подгонкой. Кэши `soil_{Atbasar,Esil,Shortandy,Bulandy,Kokshetau}.json`
  с null-слоями сохранены как доказательство.
- Агрегация: среднее глубин 0-5cm и 5-15cm после деления на `d_factor`
  из ответа (nitrogen/100, ph/10, soc/10, clay/10).

Решение по шагу 2: **панель `panel_v4.csv` НЕ собирали, модели НЕ переобучали.**
Причина: soil-покрытие 5/10 — статичные признаки с 50% пропусков нельзя
использовать честно (импутация = моки, дроп 5 районов = потеря половины
панели). Остались модели v3 (`models/lgbm_*.pkl` без изменений).
- Честный подэксперимент (wheat, только 5 soil-районов, hold-out 2021–2025,
  n_test=25): v3 MAE 1.267 / R2 0.670 → v3+soil MAE 1.093 / R2 0.728.
  Сигнал есть, НО оговорка: soil статичен по району (≈ district-intercept
  на 5 районах, риск запоминания средних района, а не агрономии почвы).
  Вывод: добирать покрытие (альтернативный источник почвы / смещение
  центроида к пашне с фиксацией) и только потом честно сравнивать v4 на
  полном покрытии. Сейчас — v3.

## 2. Интервалы — конформные из OOF-остатков train (без hold-out утечек)

Артефакты: `src/intervals.py` (`conformal_interval(y_pred, crop) -> (lo, hi)`),
`metrics/conformal.json` (квантили q10/q90 OOF-остатков бленда на train ≤2020,
TimeSeriesSplit(5)), `metrics/intervals.json` (покрытие hold-out 2021–2025).

| crop | q10 / q90 (train OOF) | conformal покрытие / ширина | gauss ±1.28σ покрытие / ширина |
|------|----------------------|-----------------------------|-------------------------------|
| spring_wheat | -1.121 / +1.396 | **0.620** / 2.52 | 0.600 / 2.68 |
| barley | -1.145 / +1.399 | **0.620** / 2.54 | 0.600 / 2.70 |
| oats | -1.231 / +1.575 | **0.600** / 2.81 | 0.580 / 3.02 |
| sunflower | -0.638 / +0.792 | **0.580** / 1.43 | 0.540 / 1.35 |
| rapeseed | -0.534 / +0.515 | 0.000 / 1.05 | 0.000 / 1.28 |
| flax | -0.442 / +0.609 | 0.160 / 1.05 | **0.260** / 1.30 |

Вывод честно:
- Конформные интервалы уже и асимметричны (ловят смещение модели), на
  wheat/barley/oats/sunflower покрытие чуть ВЫШЕ гауссовых при меньшей
  или сравнимой ширине — рекомендуем к использованию.
- Оба типа НЕ дотягивают до номинальных 0.80: сдвиг распределения
  2021–2025 vs train (скачок масличных, prelim-2025). Номинал 80% на
  hold-out не заявляем — заявляем фактическое покрытие из таблицы.
- rapeseed 0.000 у обоих: структурный разрыв 2024–2025 больше любой
  train-ширины (модель experimental — честно, см. METRICS.md).
- flax: конформный ХУЖЕ гауссова (0.160 < 0.260) — узкий train-интервал
  сильнее бьёт по покрытию при сдвиге. Тоже фиксируем, не прячем.
