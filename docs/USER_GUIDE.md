# Qagro — руководство пользователя

> Для фермера и для жюри. Простыми словами: прогноз урожайности-2026, риск засухи, страховка-ориентир. Акмолинская область: 10 районов × 6 культур. Детали для разработчиков — в `README.md`.

## 1. Что нужно

- Компьютер с **Windows 10/11**.
- **Python 3.12** (скачать с python.org, при установке поставить галочку Add to PATH).
- **Интернет** — для живых данных погоды (Open-Meteo) и спутниковых проверок.
- **Без интернета офлайн-демо тоже работает**: прогноз считается по сохранённым данным (нейтральный сценарий — средний май–август 2016–2025). Живые данные — по возможности (best-effort).

## 2. Установка за 5 минут

1. Распакуйте папку `Qagro`.
2. Откройте её в командной строке (`cmd`) и выполните:
```bat
python -m pip install -r requirements.txt
```
3. Для Telegram-бота один раз скопируйте пример настроек:
```bat
Copy-Item .env.example .env
```
4. Токен бота: откройте Telegram, найдите **@BotFather**, отправьте `/newbot`, придумайте имя. BotFather выдаст токен вида `123456:ABC...`. Откройте файл `.env` в Блокноте и замените `xxx` на этот токен:
```
TELEGRAM_BOT_TOKEN=ваш_токен_сюда
```
Токен хранится только в `.env`, в коде его нет.

## 3. Запуск

Самый простой способ — двойной клик по `.bat` в папке `Qagro`:

| Файл | Что запускает |
|---|---|
| `run_web.bat` | Веб-дашборд (`python -m streamlit run app\streamlit_app.py`) |
| `run_api.bat` | API на порту 8000 (`python -m uvicorn src.api:app --host 127.0.0.1 --port 8000`) |
| `run_bot.bat` | Telegram-бот (`python -m src.bot`, нужен `.env` с токеном) |

Вручную (PowerShell):
```powershell
python -m pip install -r requirements.txt
python -m streamlit run app/streamlit_app.py
python -m uvicorn src.api:app --host 127.0.0.1 --port 8000
Copy-Item .env.example .env
python -m src.bot
```

Docker (все три сервиса сразу):
```powershell
docker compose up --build
```
Адреса: API — `http://localhost:8000/health`, веб — `http://localhost:8501`. Бот читает `.env` (`TELEGRAM_BOT_TOKEN`); папка `./data` хранит SQLite-кэш.

## 4. Telegram-бот

Путь: `/start` → выбери язык (RU/KZ/EN) → выбери район кнопкой (10 районов Акмолы) → выбери культуру (пшеница, ячмень, овёс, подсолнечник, рапс, лён🧪) → получишь карточку: прогноз + риск 🟢🟡🔴 + кнопки 📄 PDF-отчёт / 🔄 Новый прогноз.

Все команды (примеры в одну строку):

- `/start` — начать заново. Пример: `/start` → Есильский → Пшеница яровая.
- `/more` — показать список дополнительных команд. Пример: `/more`.
- `/gis` — поля со спутника (NDVI, залежи). Пример: выбери район, затем `/gis`.
- `/spray` — окно опрыскивания (ветер/дождь, 48 ч). Пример: `/spray` после выбора района.
- `/guide <жалоба>` — совет по проблеме словами. Примеры: `/guide саранча`, `/guide засуха`, `/guide ржавчина`. Без текста — записи выбранной культуры + подсказка.
- `/fields` — мои поля. Пример: `/fields` — всего 115 (проверено 109 OSM, пример 6 demo).
- `/elevators` — элеваторы. Пример: `/elevators` — список 12 (координаты примерные, карта Qoldau).
- `/alerts` — угрозы 7 дней (заморозки/жара/ливни). Пример: выбери район, затем `/alerts`.
- `/compare` — сравнить 2 культуры в районе. Пример: `/compare` → пшеница vs ячмень.
- `/about` — о команде и источниках. Пример: `/about`.

Геолокация: нажми 📍 и отправь своё местоположение — бот сам найдёт ближайший район и ближайший элеватор (расстояние считает по формуле гаверсинуса).

Что значит 🧪: пробный прогноз (мало данных, сейчас — лён масличный). Ориентируйся на среднее за 5 лет, а не на точное число.

Без токена: `run_bot.bat` сам скопирует `.env.example` в `.env` и попросит вставить токен. Пока токена нет — пользуйся веб-демо (`run_web.bat`), бот просто пишет «токена нет — это нормально» и не запускается.

## 5. Веб-дашборд

Обучение за 1 минуту (подсказки на экране):

1. Выберите район (шаг 1) и культуру (шаг 2) — ответ появится в шаге 3.
2. Зелёный — спокойно, жёлтый — следите, красный — готовьтесь. Значок 🧪 — пробный прогноз.
3. Кнопка PDF сохраняет отчёт; вкладки ниже — карты, календарь и цифры для агронома.

Вкладки:

- 🗺 **Карты** — риски по районам + таблица; внутри: Риски, Поля и элеваторы, Со спутника.
- 📊 **Для агронома** — график истории, метрики модели, кнопка CSV.
- 🚜 **Моё хозяйство** — свои поля, журнал заметок, окно опрыскивания.
- 🔬 **Справочник и деньги** — болезни/вредители, NPK-баланс, экономика.
- ⚖️ **Сравнение культур** — 2–4 культуры рядом: урожай, риск, выплата, вывод.
- 📅 **Календарь и алерты** — сроки сева/уборки + угрозы 7 дней.
- ℹ **О проекте** — как это работает, источники, честные ограничения.

Кнопка **«Скачать отчёт PDF»** сохраняет карточку в файл. Кнопка **«▶ Показать пример (Есильский + пшеница)»** сразу ставит демо: Есильский район + пшеница яровая (в демо `reports/risk_example.json`: риск 🟡 35.0, выплата-ориентир ~51 тг/га).

## 6. API (для агронома и жюри)

Запусти `run_api.bat`, затем в `cmd` (Windows-синтаксис, кавычки двойные, внутри `\"`):

```bat
curl.exe http://127.0.0.1:8000/health
curl.exe -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d "{\"district_en\":\"Esil\",\"crop\":\"spring_wheat\"}"
curl.exe -X POST http://127.0.0.1:8000/report -H "Content-Type: application/json" -d "{\"district_en\":\"Esil\",\"crop\":\"spring_wheat\"}" --output report.pdf
curl.exe "http://127.0.0.1:8000/gis?district_en=Esil&max_fields=6"
curl.exe "http://127.0.0.1:8000/agrodata?district_en=Esil&crop=spring_wheat&lang=ru"
curl.exe "http://127.0.0.1:8000/compare?district_en=Esil&crops=spring_wheat,barley&lang=ru"
```

Что возвращают: `/health` — жив ли сервер; `/predict` — прогноз+риск+страховка; `/report` — PDF-файл; `/gis` — NDVI-мониторинг полей; `/agrodata` — сверка с Казгидромет; `/compare` — сравнение культур. Подробности полей ответа — в `README.md` (раздел API).

## 7. Офлайн-режим

Без сети работает: прогноз (нейтральный сценарий), риски из сохранённого файла, страховка-ориентир, календарь сева, справочник, PDF, свои поля и журнал.

Признаки приблизительности (не пугайтесь, это честные плашки):

- 📡 «Интернет слабый — посчитано по сохранённым данным».
- ⚠️ «Пробный прогноз — ориентируйтесь на среднее за 5 лет» + значок 🧪 у льна.
- «Файл рисков не найден — таблица посчитана из прогноза модели (офлайн)».
- 🛰 «Спутник офлайн» и пустые NDVI — число не выдумывается.
- В `/alerts` и `/agrodata` при обрыве сети приходит `200` с полем `error`, а не выдуманные угрозы.

## 8. Troubleshooting

| Симптом | Причина | Команда-фикс |
|---|---|---|
| `NO .env!` / «Token is still xxx» при `run_bot.bat` | Нет токена @BotFather | Вставь токен в `.env` (`TELEGRAM_BOT_TOKEN=...`), запусти снова; либо пользуйся `run_web.bat` |
| `'streamlit' / 'uvicorn' is not recognized` | Консольных команд нет в PATH | Запускай только через `python -m`: `python -m streamlit run app/streamlit_app.py`, `python -m uvicorn src.api:app --host 127.0.0.1 --port 8000` |
| `Address already in use: 8000 / 8501` | Порт занят другим запуском | Закрой старое окно; либо `netstat -ano \| findstr 8000`, заверши процесс в Диспетчере задач |
| «Спутник офлайн», пустые алерты, `error` в API | Нет интернета | Это нормально: работай с сохранёнными данными; проверь сеть позже |
| Бот пишет «токена нет» и завершается | `TELEGRAM_BOT_TOKEN` пуст или `xxx` | Это штатное завершение (не ошибка): впиши токен в `.env` или смотри веб-демо |
| В PDF вместо букв точки/кракозябры | Нет шрифта с кириллицей (код ищет DejaVuSans/Arial, иначе Helvetica) | Windows: проверь `C:\Windows\Fonts\DejaVuSans.ttf` или Arial; Docker: пакет `fonts-dejavu` уже ставится образом |

## 9. FAQ

1. **Насколько точен прогноз?** Пшеница/ячмень/овёс — сильные модели (R² 0.66/0.65/0.74 на hold-out 2021–2025, лучше среднего за 5 лет). Подсолнечник/рапс — лучше бейзлайна по ошибке, но с оговорками. Лён 🧪 — честный пробный baseline. Интервал «80%» фактически покрывает ~0.48–0.66 — мы показываем факт, а не обещание.
2. **Это страховой тариф?** Нет. Это decision support: шанс недобора и ориентир выплаты (цена пшеницы/ячменя 95 000 тг/т, порог 0.8, субсидия 0.8). Тариф определяет страховая.
3. **Мои данные (поля, геолокация) уходят куда-то?** Геолокация используется только чтобы найти ближайший район. «Мои поля» и журнал хранятся локально (SQLite), на сервер не отправляются.
4. **Какие районы и культуры покрыты?** 10 районов: Зерендинский, Бурабайский, Атбасарский, Есильский, Жаксынский, Шортандинский, Целиноградский, Сандыктауский, Буландынский, Кокшетау. 6 культур: пшеница яровая, ячмень, овёс, подсолнечник, рапс, лён масличный🧪.
5. **Что означают 🟢🟡🔴?** Декадный индекс засухи 0–100: 🟢 <35 спокойно, 🟡 35–60 следите, 🔴 >60 готовьтесь (осадки+жара+сухие дни).
6. **Откуда цифры?** Бюро нацстатистики РК, NASA POWER, Open-Meteo (ERA5), FAOSTAT, OpenStreetMap, Qoldau (элеваторы), Copernicus/Sentinel-2. Ссылки и права — в `README.md`.
7. **Что показать жюри за 2 минуты?** Бот: `/start` → Есильский → пшеница → PDF. Веб: кнопка-примера (Есильский + пшеница) → вкладки Карты и Сравнение. API: `GET /health` + `POST /predict`. Сценарий по секундам — `docs/demo_script.md`.
