# Qagro — outline презентации (10 слайдов)

## Слайд 1. Проблема
- Акмола — житница KZ: засухи 2010/2012/2019/2021 роняли урожай вдвое; решения — постфактум.
- Фермеру не хватает: локального прогноза, раннего сигнала засухи, честной страховки.
- Цена ошибки — −30–50% выручки за сезон.
- Картинка: карта Акмолинской области + мини-график просадок урожайности из панели.

## Слайд 2. Решение
- Qagro: прогноз 2026 по району + декадный светофор риска + страховка + совет по севу (RU/KZ/EN).
- Три входа: Telegram-бот, FastAPI, Streamlit-дашборд с PDF/CSV/GeoJSON.
- Decision support, не «чёрный ящик»: интервал + SHAP-факторы + формула риска.
- Картинка: схема «данные → модель → риск → страховка → бот/веб/PDF».

## Слайд 3. Демо
- Путь за 30 сек: /start → язык → Есильский → пшеница → прогноз + 🟡 + 1558 тг/га + PDF.
- Живой пример Esil vs Zerenda (🟡 35.0 vs 🟢 28.5).
- QR на бота + ссылка на Streamlit.
- Картинка: скриншоты бота (язык/район/карточка прогноза) + `reports/risk_example.json`.

## Слайд 4. Данные
- Панель 420 строк (10 районов × 21 год × 2 культуры), 0 NaN; БНС-якоря + NASA POWER + Open-Meteo ERA5.
- Фичи MJJA: tmean/precip/GDD5/heat30/dry_max/ET0/p30_anom + lat/lon/yield_lag1.
- Честно: район = даунскейлинг области на центроиды `config/districts.yaml`.
- Картинка: схема панели + таблица первых строк из `data/processed/data_card.md`.

## Слайд 5. Модель
- Бейзлайн = среднее 5 лет; LGBM per-crop (TimeSeriesSplit 5 + LOO 2020–2025).
- Прогноз 2026: y_pred + 80% интервал (OOF residual_std) + топ-3 SHAP.
- 4 культуры без данных — APPROX-масштаб от пшеницы с флагом.
- Картинка: блок-схема `src/train.py → src/predict.py` + SHAP топ-3 (`metrics/shap_*.json`).

## Слайд 6. Метрики
- Пшеница: бейзлайн MAE 2.68 / R² −0.26 → LGBM MAE 1.46 / R² 0.55.
- Ячмень: бейзлайн 2.78 / −0.25 → LGBM 1.52 / 0.54 (hold-out 2021–2025, n=50).
- APPROX-культуры — без метрик (данных нет, так и заявлено).
- Картинка: `metrics/plots/scatter_spring_wheat.png` + `metrics/plots/scatter_barley.png` + таблица метрик.

## Слайд 7. Эффект (тг/га)
- Esil/пшеница: P_loss 0.23, expected payout **1558 тг/га**; Zerenda/пшеница: 0.03, **150 тг/га**.
- Ранний сигнал (🟡/🔴 декады июля) → сдвиг сева 12–18 мая + влагосбережение.
- Экономия/защита маржи: страховка покрывает просадку ниже страйка 0.8×mean5.
- Картинка: карточки `Esil_insurance_wheat` vs `Zerenda_insurance_wheat` из `reports/risk_example.json`.

## Слайд 8. Масштаб
- Сегодня: 10 районов Акмолы, 6 культур, 3 языка, Docker (api+bot+web).
- Завтра: все области KZ (тот же пайплайн `src/fetch_all.py`), поля вместо центроидов.
- Интеграции: ERA5-Land, Sentinel-2 NDVI, e-АПК / Qoldau / страховщики.
- Картинка: Folium-карта рисков (10 центроидов) из Streamlit + стрелка «Акмола → весь KZ».

## Слайд 10. Планы
- **ERA5-Land**: почвенная влага и реанализ вместо null-soil (уже запрошен hourly `soil_moisture_3_9cm`).
- **Sentinel-2 NDVI**: вегетационный индекс по декадам как фича и триггер выплат.
- **e-АПК интеграция**: поля/посевы/господдержка + пилоты со страховщиками (индексное страхование).
- Картинка: roadmap Q4 2026 → 2027 (ERA5 → NDVI → e-АПК → пилоты).
